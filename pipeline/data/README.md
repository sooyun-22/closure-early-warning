# 데이터

원본 데이터는 용량이 커서(수 GB) 저장소에 포함하지 않았습니다. 아래 공개 데이터를 받아 이 폴더에 두면 파이프라인을 실행할 수 있습니다.

| 데이터 | 출처 | 사용 단계 |
|---|---|---|
| 서울시 상권분석서비스: 점포, 추정매출, 소비, 길단위인구, 상주인구, 직장인구, 집객시설 (상권 단위) | 서울 열린데이터광장 | 1단계 |
| 서울시 상권분석서비스 영역 (폴리곤, `boundary.shp`) | 서울 열린데이터광장 | 2단계 공간 조인 |
| 소상공인시장진흥공단 상가(상권)정보, 서울 분기별 스냅샷 | 공공데이터포털 | 2단계 |
| 서울시 업종별 인허가 정보 8종: 일반음식점, 휴게음식점, 미용업, 이용업, 담배소매업, 의원, 종합체육시설업, 통신판매업 | 서울 열린데이터광장 | 2단계 라벨 보정 |

각 노트북이 읽는 정확한 파일명은 노트북 상단의 경로 설정 셀에서 확인할 수 있습니다.

## 주요 중간 산출물

파이프라인을 실행하면 이 폴더에 아래 파일이 생성됩니다.

- `1단계_학습데이터_최종.csv`: 1단계 학습 테이블 (약 1GB)
- `2단계_학습데이터_최종_인허가포함_라벨보정.parquet`: 2단계 학습 테이블
- `2단계_학습데이터_최종_인허가포함_피처완료.parquet`: 2단계 피처 생성 완료본 (Action Plan 입력)
